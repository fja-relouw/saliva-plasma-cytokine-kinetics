# Data

Put these two files in this folder before running `run_all.m`:

| File | Content |
|---|---|
| `DEDICATE-LPS SALIVA.xlsx` | sheets `Olink flex saliva` (raw Olink Flex export), `plasma cytokines ` (tidy plasma data: id, day, time, cyto, pg/mL, Group) and `saliva protein` (salivary total protein) |
| `DEDICATE-LPS_study_export_20250908.csv` | study database export (screening characteristics for Table 1), semicolon-separated |

The files contain individual participant data and are not part of this repository; they are
available as described in the data sharing statement of the article.
